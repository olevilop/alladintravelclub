

## Заменить дни на даты в маршруте круиза «Антарктический полуостров и море Уэдделла на Scenic Eclipse»

### Что делаем

Заменяем числовые дни (1–16) на конкретные даты в блоке «Маршрут по дням». Пользователь указал 6 пунктов — текущие 16 дней заменяются на 6 новых записей с датами.

### Технические изменения

**1. `src/data/tours.ts`** — тип `TourDay`
- Изменить `day: number` → `day: number | string`, чтобы поддержать строковые даты.

**2. `src/data/tours.ts`** — маршрут тура `antarctic-penguins`
- Заменить 16 записей itinerary на 6:
  - `{ day: "03.12.2026", title: "Стэнли, Фолкленды", description: "..." }`
  - `{ day: "04.12.2026", title: "Фолклендские острова", description: "..." }`
  - `{ day: "05.12.2026", title: "В море", description: "..." }`
  - `{ day: "06.12.2026 - 15.12.2026", title: "Антарктика", description: "..." }`
  - `{ day: "16.12.2026 - 17.12.2026", title: "В море", description: "..." }`
  - `{ day: "18.12.2026", title: "Ушуайя — вылет", description: "..." }`

Названия и описания сохраняются из существующих записей (объединяются по смыслу для диапазонов дат).

**3. `src/pages/TourDetail.tsx`** — рендеринг бейджа дня
- Строка ~139: изменить `{day.day} день` → для числовых значений оставить `{day.day} день`, для строковых — выводить строку как есть (без суффикса «день»).

Три правки в двух файлах.
