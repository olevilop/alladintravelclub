

## Показать полный маршрут (без дедупликации) на карточке тура

**Проблема:** Компонент `RouteMap.tsx` фильтрует точки маршрута по уникальным названиям, поэтому «Пролив Дрейка» и «Ушуайя» показываются только один раз. Вместо полного маршрута «Буэнос-Айрес → Ушуайя → Пролив Дрейка → Антарктида → Пролив Дрейка → Ушуайя» отображается только «1. Буэнос-Айрес 2. Ушуайя 3. Пролив Дрейка 4. Антарктида».

**Решение:** В `RouteMap.tsx` убрать дедупликацию и выводить все точки маршрута по порядку.

### Техническая деталь

**Файл: `src/components/RouteMap.tsx`**, строки 27–29 — заменить фильтр `uniqueLabels` на простой список всех точек с лейблами:

**Было:**
```ts
const uniqueLabels = points.filter(
  (p, i, arr) => p.label && arr.findIndex((a) => a.label === p.label) === i
);
```

**Станет:**
```ts
const routeLabels = points.filter((p) => p.label);
```

И в JSX (строка 56) заменить `uniqueLabels.map` на `routeLabels.map`, а `key={p.label}` на `key={i}`.

Одна правка, один файл.
