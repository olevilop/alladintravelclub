## Цель
Добавить новый групповой тур по Китаю `china-zhangjiajie-2026` по образцу `china-grand-tour-2026`, переиспользуя существующие компоненты (TourCard, TourInfo-сайдбар, TourPricing с dropdown, SimilarTours).

## Что уже работает «из коробки»
- **Карточка в /china-tours и на главной** — `ChinaToursPage` рендерит весь массив `chinaTours`; `ToursSection` (главная) тоже подтягивает `chinaTours`. Достаточно добавить запись в массив.
- **Хлебные крошки** — `TourDetail` строит цепочку «Главная → Туры по Китаю → {name}» автоматически по `region === "Китай"`.
- **TourInfo-сайдбар** — после прошлой правки порядок строк уже: Экскурсионный тур → Групповой тур → Континент → Страна → Длительность → Цена → Маршрут. Поля заполняются из `category`, `badge`, `region`, `days`, `price`, маршрут — из `name` (длинная форма) или поля для линии маршрута.
- **TourPricing dropdown** — если у тура есть `groupPricing`, рендерится тот же UI, что в Гранд Туре.
- **Похожие туры в Китай** — компонент `SimilarTours` уже фильтрует по `region === "Китай"` и показывает карусель TourCarousel со стрелками и свайпом. Отдельный `SimilarChinaToursSection` создавать не нужно — добавление нового тура автоматически появит его в карусели на странице Гранд Тура и наоборот.
