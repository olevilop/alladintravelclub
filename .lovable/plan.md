## Цель
Заменить блок «Маршрут по дням» в данных тура `seychelles-tropical-rhythms` на новые 8 пунктов с датами вместо номеров дней. Бейдж в UI уже поддерживает строковые значения (`day: number | string`, см. `TourDetail.tsx`: `typeof day.day === 'number' ? '${day.day} день' : day.day`), так что отрисовка дат работает «из коробки».

## Изменения

### `src/data/tours.ts` — `seychelles-tropical-rhythms.itinerary`
Полностью заменить массив на 8 элементов с `day` = дата (строка) и предоставленными заголовками/описаниями:
- "27.12.2026" — «Остров Маэ, Сейшельские острова»
- "28.12.2026" — «Пролив Сент-Анн — остров Кузен»
- "29.12.2026" — «Остров Праслин»
- "30.12.2026" — «Остров Ла-Диг — остров Кюрьёз»
- "31.12.2026 🎄" — «Остров Кюриёз — Новогодняя ночь»
- "01.01.2027" — «Остров Ариде»
- "02.01.2027" — «Остров Маэ»
- "03.01.2027" — «Завершение круиза»

## Результат
В блоке «Маршрут по дням» вместо «1 день», «2 день» и т.д. будут отображаться даты-бейджи (с ёлочкой 🎄 на 31.12), а описания обновлены на новый текст.
