

## Добавление блока «Стоимость тура на 1 человека» на страницы туров по Южной Корее

### Что добавить

Новый блок в боковой панели страницы тура между картой маршрута (`RouteMap`) и формой бронирования (`TourBookingForm`):

**Стоимость тура на 1 человека**
| Размещение | Цена |
|---|---|
| 1 чел. в номере | $3 312 (273 250 ₽) |
| 2 чел. в номере | $2 374 (195 900 ₽) |
| 3 чел. в номере | $2 255 (186 050 ₽) |

### Подход

В `src/data/tours.ts` уже есть структура `hotelPricing` с полями `categories` и `rows[].prices`, которая используется в `TourDetail.tsx` (строки 269–301) для рендера селекта с ценами по отелям. Однако для корейских туров логика проще — единый прайс по размещению без выбора отеля.

**Решение**: добавить новое опциональное поле `occupancyPricing` в интерфейс `Tour` со структурой:
```ts
occupancyPricing?: {
  rows: Array<{ label: string; price: string }>;
}
```

### Изменения

1. **`src/data/tours.ts`** — расширить интерфейс `Tour` полем `occupancyPricing` и добавить одинаковый блок данных к 5 турам по Южной Корее:
   - `korea-jeju-island` («Большое корейское путешествие»)
   - `korea-hanok-culture` («В царство лотосов»)
   - `korea-busan-coastal` («День рождения Будды и Восточное море»)
   - `korea-temple-stay` («12 дней: столица, регионы, Чечжу»)
   - Любой другой тур с `region === "Южная Корея"` (проверю при реализации)

2. **`src/pages/TourDetail.tsx`** — добавить компактный блок-таблицу между `<RouteMap />` и блоком `hotelPricing` (строка ~268), стилизованный аналогично существующим прайс-карточкам в боковой панели (`bg-card border border-border p-4`, заголовок `text-xs uppercase tracking-widest`, строки с `flex justify-between`).

### Что НЕ меняется

- Существующие блоки `hotelPricing` и `excursionPricing` (если есть у других туров) остаются нетронутыми
- Поле `price` в туре (используется в карточках каталога и в sidebar в строке «Стоимость от ...») не меняется
- Цены идентичны для всех 5 корейских туров согласно вашему сообщению

### Память

После реализации сохраню новое правило в `mem://features/tour/occupancy-pricing` — компактный блок цен по типу размещения для туров по Южной Корее, отображаемый между картой маршрута и формой бронирования.
