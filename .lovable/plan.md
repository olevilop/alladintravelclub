# Редизайн страницы лайнера

Файл: `src/pages/cruises/LinerDetailPage.tsx`

## Изменения

### 1. Hero
- Оставляем как есть (фото + название + короткое описание).
- Удаляем надпись «Премиальный флот» над заголовком.

### 2. Хлебные крошки
- Было: `Круизы › Лайнеры › {Название}`
- Станет: `Лайнеры › {Название}` (убираем пункт «Круизы»).

### 3. Двухколоночный макет (как на странице тура)
Под Hero — контейнер с двумя колонками:

```text
┌─────────────────────────────┬──────────────────┐
│  Левая колонка (8/12)       │  Правая (4/12)   │
│  Табы:                      │  Карточка        │
│   [О судне][Каюты]          │  «Технические    │
│   [План палуб][Круизы]      │  характеристики» │
│  ───────────────────        │  (sticky)        │
│  Контент активной вкладки   │                  │
└─────────────────────────────┴──────────────────┘
```

- Правая колонка: текущая карточка «Технические характеристики» переезжает сюда, делаем `sticky top-24`, список спеков в столбик (label сверху — value снизу), оформление как в сайдбаре `TourDetail.tsx`.
- Левая колонка: компонент `Tabs` из `@/components/ui/tabs` с 4 вкладками:
  - **О судне** — `liner.longDescription` (текущая двухколоночная вёрстка остаётся внутри вкладки).
  - **Каюты** — сетка `liner.cabins` (как сейчас).
  - **План палуб** — `liner.deckPlanImage`.
  - **Круизы** — список `linerTours` (как сейчас, сетка карточек).
- Если у лайнера нет данных для какой-то вкладки — соответствующий триггер не рендерится.

### 4. Карусель фото лайнера
Под двухколоночным блоком, на всю ширину контейнера:
- Заголовок «Галерея».
- Горизонтальная карусель из `liner.gallery` по образцу `src/components/TourCarousel.tsx`:
  - 4 фото в строке на десктопе (`lg:w-[calc(25%-18px)]`), 2 на планшете, 1 на мобиле.
  - Скрытый скроллбар, snap-x, кнопки‑стрелки слева/справа при возможности прокрутки.
  - Клик по карточке открывает существующий `Dialog` лайтбокс.
- Используем тот же паттерн прокрутки, что и в `TourCarousel`, но без цены/бейджей — только фото.

### 5. Прочее
- `SpecialOffers`, `NewsletterSocial`, `Footer` — оставляем без изменений.
- Семантические токены (`bg-card`, `border-border`, `text-primary` и т.д.) — без хардкода цветов.
- Никаких изменений в `liners.ts`, `App.tsx` и других файлах не требуется.

## Технические детали
- Таб по умолчанию: `about` (О судне); если `longDescription` пуст — первый доступный.
- Карусель — выносим в локальный подкомпонент внутри `LinerDetailPage.tsx` (или маленький отдельный файл `LinerPhotoCarousel.tsx`), чтобы не смешивать с турами.
- `sticky` правой колонки работает только на `md+`, на мобиле — спеки идут сверху над табами.
