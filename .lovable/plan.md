## Новый тур: Острова Раджа-Ампат (Индонезия)

Создать новый тур по аналогии с круизами по Меконгу/Янцзы — простое добавление данных, страница рендерится существующим динамическим маршрутом `/tour/:id`.

### Файлы и правки

1. **`src/data/tours.ts`** — добавить новый объект тура в массив `tours` (после Меконга, перед Янцзы или в конце экспедиционного блока):
   - `id: "indonesia-raja-ampat-cruise"`
   - `name: "Острова Раджа-Ампат"`, `region: "Индонезия"`, `category: "expedition"`
   - `days: 8`, `price: "от $12 150"`, `badge: "🇷🇺 РУССКАЯ ГРУППА"`
   - `subtitle`, `description` — из брифа
   - `image` + `gallery` (5 placehold.co с тропической палитрой)
   - `itinerary` — 8 дней в формате `{ day: "27.02.2027", title, description }`
   - `included` (10 пунктов) и `notIncluded` (7 пунктов) — из брифа
   - `difficulty: "Лёгкая"`, `groupSize: "Гарантированная русская группа"`
   - `startDates: ["27.02.2027 — 06.03.2027"]`
   - `shipName: "Aqua Blu 5*"`, `shipImage: placehold.co`
   - `extras` — описание яхты Aqua Blu (мультистрочный текст, как у Scenic Spirit)
   - `cabinPricing` с 3 категориями: Люкс III ($12 150), Люкс II ($15 230), Люкс I ($16 850)
   - `paymentTerms` и `cancellationTerms` — стандартные

2. **`src/data/tourRoutes.ts`** — добавить ключ `"indonesia-raja-ampat-cruise"` с координатами 8 точек:
   - Соронг (-0.88, 131.25) → Wayag/Тысяча Храмов (-0.16, 130.05) → Йиллет (-0.55, 130.55) → Дарам (-2.25, 130.65) → Сабуда (-2.20, 132.45) → Пролив Нептуна (-2.30, 130.55) → Фибиасет (-2.35, 130.50) → Капаткол/Misool (-1.95, 130.10) → Bu/Кофиу (-1.30, 130.40) → Соронг

### Что НЕ трогаем
- Существующие туры, стили, шрифты, палитра, дизайн-система
- Header/Footer/навигация
- Компонент `TourCard`, `SpecialOfferBadge`, `TourDetail.tsx`, `RouteMap.tsx`

### Технические детали
- Страница тура — динамическая (`/tour/:id` через `TourDetail.tsx`), отдельный JSX-файл создавать не нужно
- Все блоки (TourHero, TourItinerary, TourPricing, TourIncluded, TourTerms, ShipInfo, TourManager, TourBookingForm, TourBreadcrumbs) уже отрендерены `TourDetail.tsx` на основе полей объекта тура
- Бейдж `🇷🇺 РУССКАЯ ГРУППА` рендерится автоматически из поля `badge`
- Бейдж страны "ИНДОНЕЗИЯ" в правом верхнем углу карточки рендерится из `region`
- Описание судна Aqua Blu идёт в поле `extras` — `TourDetail.tsx` использует общий блок ShipInfo для всех судов, отдельный компонент создавать не требуется (текст и `shipImage` уже параметризованы)
- Ссылка на тур из карты будет работать, попадание в "Спецпредложения" и "Экспедиционные круизы" — автоматически по `category: "expedition"`

### Результат
- Карточка появится в карусели "Экспедиционные круизы" и в "Спецпредложениях" на главной
- Доступна страница `/tour/indonesia-raja-ampat-cruise` со всеми блоками
- Маршрут отображается на SVG-карте
