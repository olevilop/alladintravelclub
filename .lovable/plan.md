

# Premium Luxury Travel Club Website

## Дизайн-система
- **Цвета**: Тёмный фон (#0a0a0f, #0d1b2a), золотые акценты (#c9a96e, #d4af37), белый текст
- **Шрифты**: Элегантная типографика с serif для заголовков, sans-serif для текста
- **Стиль**: Минимализм + luxury, большие фоновые изображения, плавные анимации

## Структура (одностраничный сайт с навигацией)

### Навигация
- Фиксированная прозрачная шапка с логотипом и меню
- Золотая кнопка "Оставить заявку"

### 1. Hero-секция
- Полноэкранное фото с overlay (ледник/океан)
- Анимированный заголовок и подзаголовок на русском
- CTA кнопка "Подобрать путешествие"
- Scroll-индикатор

### 2. О компании
- Блок с цифрами (20+ лет, 500+ экспедиций, 50+ стран, 90% повторных клиентов)
- Краткий текст о миссии и экспертности
- Анимация при скролле

### 3. Направления
- 6 карточек с hover-эффектами: Арктика, Антарктида, Африка, Азия, Острова, Южная Америка
- Каждая с атмосферным фото и кратким описанием

### 4. Каталог туров
- Фильтр по регионам (табы)
- Карточки туров: фото, название, длительность, цена/"по запросу", кнопка "Подробнее"
- 6-8 примеров туров

### 5. Почему мы
- Иконки + текст: опыт, безопасность, эксклюзивные маршруты, премиум-партнёры
- Золотые акценты на иконках

### 6. Отзывы
- Карусель с историями путешественников
- Фото, имя, маршрут, эмоциональный текст-отзыв

### 7. FAQ
- Аккордеон с вопросами и ответами
- Стилизован под luxury-тему

### 8. CTA + Форма заявки
- Форма: имя, телефон, email, пожелания
- Атмосферный фон

### 9. Подписка + Footer
- Email-подписка на спецпредложения
- Контакты, соцсети, копирайт

## Анимации
- Fade-in при скролле для всех секций
- Hover-эффекты на карточках (scale + overlay)
- Плавные переходы между состояниями

## Адаптивность
- Полностью респонсивный дизайн для всех экранов
