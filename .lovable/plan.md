

## Заменить «О нас» на «Компания» в подвале

**Файл: `src/components/Footer.tsx`**

В массиве `footerLinks` заменить объект с `title: "О нас"` на:

```js
{
  title: "Компания",
  links: ["О нас", "Наша команда", "Трансфер", "Страхование", "Бронирование гостиниц", "Билеты на паром", "Визы"],
}
```

Пункты останутся текстом без ссылок (аналогично «Программы» и «Круизы»), пока страницы не будут созданы.
