

## Заменить колонку «Направления» на «Туры» с кликабельными ссылками

**Файл: `src/components/Footer.tsx`**

1. Заменить первый элемент массива `footerLinks` — колонку «Направления» — на отдельный блок «Туры», который рендерится вне общего цикла `footerLinks.map()`.

2. Новый блок «Туры» содержит список `Link`-элементов с маршрутами:
   - Япония → `/japan-tours`
   - Китай → `/china-tours`
   - Россия → `/russia-tours`
   - Южная Корея → `/korea-tours`
   - Северная Корея → `/nkorea-tours`

3. Каждая ссылка оформлена как `<Link>` с `onClick={() => window.scrollTo(0, 0)}` для прокрутки к верху страницы, со стилями аналогичными остальным пунктам футера (символ `›`, hover-эффект).

4. Удалить объект `{ title: "Направления", links: [...] }` из массива `footerLinks`.
