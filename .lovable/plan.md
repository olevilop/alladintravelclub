## Логика страницы «Круизы по России»

Привести страницу к тому же принципу, что и остальные континентальные круизные страницы (Европа, Океания, Ближний Восток): показывать только круизы из массива `tours` (категории `classic` или `expedition`), у которых `region === "Россия"`.

## Изменения

**`src/pages/cruises/RussiaCruisesPage.tsx`**
- Убрать импорт `russiaTours` (это наземные туры — они остаются только на `/russia-tours`).
- Импортировать `tours` из `@/data/tours`.
- Передавать в `CategoryToursPage` отфильтрованный список:
  ```ts
  tours.filter(
    (t) => t.region === "Россия" && (t.category === "classic" || t.category === "expedition")
  )
  ```
- Остальное (заголовок, hero, breadcrumb, `hideSpecialOfferTag`) — без изменений.

**`src/data/tours.ts`**
- В словаре `regionToContinent` исправить запись `"Россия": "Азия"` (из-за неё круиз с регионом «Россия» сейчас попал бы на страницу «Круизы по Азии»). Заменить на `"Россия": "Россия"`, чтобы регион корректно ассоциировался сам с собой и не утекал в Азию.

## Что произойдёт

- Сейчас в `tours` нет круизов с `region: "Россия"`, поэтому страница временно будет пустой — это ожидаемо. Как только в каталог добавят классический/экспедиционный круиз с регионом «Россия», он автоматически появится здесь.
- Наземные туры (`russiaTours`) останутся на отдельной странице `/russia-tours` и в карусели на главной — их не трогаем.
- Страница «Круизы по Азии» больше не будет случайно подхватывать российские круизы.

## Память

Зафиксировать правило фильтрации страницы (`region === "Россия"` + категория `classic`/`expedition`) в memory `features/cruises/russia-page-logic`, чтобы в будущем не возвращаться к показу наземных туров.
