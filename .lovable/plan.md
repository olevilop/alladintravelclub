

## Обновить маршрут тура Scenic Eclipse на карточке

**Проблема:** В сайдбаре карточки тура отображается маршрут из `tourRoutes`, который сейчас содержит устаревшие точки (Ушуайя → Южные Шетландские о-ва → Порт Локрой → Залив Неко → Южная Георгия → Фолклендские о-ва → Ушуайя).

**Решение:** Заменить массив точек маршрута для `"antarctic-penguins"` в файле `src/data/tourRoutes.ts` (строки 30–38), чтобы маршрут отображался как:

**Буэнос-Айрес → Ушуайя → Пролив Дрейка → Антарктида → Пролив Дрейка → Ушуайя**
