

## Изменить порядок информации в карточке тура/круиза

**Что нужно сделать:**

Изменить порядок отображения информации в боковой карточке на странице тура/круиза:

- **Для круизов:** Название → «Экспедиционный круиз» или «Классический круиз» → Материк → Дни/ночи → Регион
- **Для туров (без category):** Название → Материк → Дни/ночи → Регион

**Технические детали:**

### 1. `src/data/tours.ts` — добавить маппинг регион → материк

```ts
export const regionToContinent: Record<string, string> = {
  "Арктика": "Арктика",
  "Антарктида": "Антарктида",
  "Африка": "Африка",
  "Россия": "Азия",
  "Ближний Восток": "Азия",
  "Острова": "Южная Америка",
  "Азия": "Азия",
  "Южная Америка": "Южная Америка",
  "Средиземноморье": "Европа",
  "Япония": "Азия",
  "Южная Корея": "Азия",
  "Китай": "Азия",
  "Северная Корея": "Азия",
  "Мальдивы": "Азия",
};
```

### 2. `src/pages/TourDetail.tsx` — перестроить sidebar-карточку

Текущий порядок: Название → (Экспедиционный круиз · регион) → Дата → Дни/ночи → Регион → ...

Новый порядок:
1. **Название** (h3)
2. **Тип круиза** (только для круизов): «Экспедиционный круиз» или «Классический круиз» с иконкой Compass/Ship
3. **Материк** (Globe icon) — из маппинга `regionToContinent`
4. Дата выбора
5. **Дни/ночи** (Moon icon)
6. **Регион** (MapPin icon)
7. Корабль, стоимость, маршрут — без изменений

Два файла, минимальные изменения.
