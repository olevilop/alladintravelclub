# Добавить тур «Пекин и парящие горы Аватара»

Новый групповой тур по Китаю по образцу `china-grand-tour-2026` / `china-zhangjiajie-2026`. Без новых компонентов — полное переиспользование шаблона.

## Что уже работает из коробки
- **Карточка в /china-tours и на главной** — `ChinaToursPage` и `ToursSection` рендерят весь массив `chinaTours`. Достаточно добавить запись.
- **URL тура** — в проекте маршрут единый: `/tour/:id`. Страница будет доступна как `/tour/china-avatar-mountains-2026` (slug = id). Отдельный путь `/china-avatar-mountains-2026` в системе не используется ни для одного тура и создавать его не требуется.
- **Хлебные крошки** — `TourDetail` строит «Главная → Туры по Китаю → {name}» автоматически по `region === "Китай"`.
- **TourInfo сайдбар** — порядок строк уже соответствует ТЗ: Экскурсионный тур → Групповой тур → Континент (Азия) → Страна (Китай) → Длительность → Цена → Маршрут.
- **TourPricing dropdown** — рендерится автоматически при наличии `groupPricing`.
- **«Похожие туры в Китай»** — компонент `SimilarTours` уже фильтрует по `region === "Китай"`, исключает текущий тур, показывает карусель TourCarousel со стрелками и свайпом, при единственном туре — обычная карточка. Новый тур автоматически появится на страницах Гранд Тура и Чжанцзяцзе, и наоборот.
- **Менеджер Виктория** — `TourManagerCard` подхватит автоматически.
