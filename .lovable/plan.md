

## Выравнивание текста маршрута

**Проблема:** Бейдж с длинной датой «06.12.2026 - 15.12.2026» шире остальных, из-за чего текст описания справа от него сдвигается вправо и не выровнен с текстами других этапов.

**Решение:** Задать фиксированную минимальную ширину левой колонке с бейджем даты, чтобы все тексты описаний начинались на одном уровне.

**Файл: `src/pages/TourDetail.tsx`**, строка 125 — добавить `min-w-[140px]` (или аналогичное значение) к контейнеру бейджа, а также выровнять его по верхнему краю (`items-start` вместо `items-center`):

```tsx
// Было:
<div className="flex flex-col items-center">

// Станет:
<div className="flex flex-col items-start min-w-[140px]">
```

Одна правка, один файл. Все бейджи получат одинаковую ширину колонки, и текст описания будет выровнен по левому краю на одном уровне.
