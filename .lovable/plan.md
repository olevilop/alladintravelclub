

## Страница «Туры по Японии»

### Что делаем
Создаём страницу `/japan-tours`, идентичную по структуре странице спецпредложений, но только с японскими турами.

### Файлы

**1. Создать `src/pages/JapanToursPage.tsx`**
Копия структуры `SpecialOffersPage.tsx`:
- Hero-баннер (h-[75vh]) со случайным изображением из `japanTours`
- Заголовок: «Туры по *Японии*»
- Подзаголовок: «Откройте для себя страну восходящего солнца»
- Список горизонтальных карточек (изображение 300px + описание + вертикальная черта 2/3 + блок информации 240px) — только `japanTours`

**2. Обновить `src/App.tsx`**
- Импорт `JapanToursPage`
- Добавить роут: `<Route path="/japan-tours" element={<JapanToursPage />} />`
