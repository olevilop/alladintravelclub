## План

Сейчас страница `/cruises/arctic` пустая, потому что туров с `region: "Арктика"` ещё нет, и hero-картинка не показывается (берётся из случайного тура).

Нужно показать hero-картинку как заглушку с заголовком «Круизы по Арктике», сохранив всю логику отображения туров на будущее.

### Шаги

1. **Сгенерировать заглушку** `src/assets/arctic-hero.jpg` — атмосферное фото Арктики (айсберги, северное сияние, ледокол), в стиле NatGeo luxury, 1920×1080.

2. **`src/pages/CategoryToursPage.tsx`** — добавить опциональный проп `fallbackHeroImage?: string`. Использовать его в hero, когда `heroTour` отсутствует:
   ```tsx
   const heroImage = heroTour?.image ?? fallbackHeroImage;
   {heroImage && <img src={heroImage} ... />}
   ```
   Логика появления туров и hero из случайного тура сохраняется — как только в данных появятся арктические туры, фон автоматически переключится на их фото.

3. **`src/pages/cruises/ArcticCruisesPage.tsx`** — импортировать `arctic-hero.jpg` и передать как `fallbackHeroImage`. Остальное (title, subtitle, breadcrumbs, фильтр по региону) уже совпадает со страницей «Круизы по Антарктиде».

### Что не меняется

- Фильтр `t.region === "Арктика"` остаётся — туры появятся автоматически при добавлении в `tours.ts`.
- Логика рендера карточек, breadcrumbs, SpecialOffers, NewsletterSocial — без изменений.
- Страница «Круизы по Антарктиде» не затрагивается (новый проп опциональный).
