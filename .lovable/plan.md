## Добавление карточки тура «Тропические ритмы Сейшельских островов»

### Что будет сделано

В блок «Экспедиционные круизы» на главной странице добавляется новая карточка-тур.

### Изменения

**`src/data/tours.ts`** — добавить новый объект в массив `tours` (в секции `category: "expedition"`):

- `id`: `seychelles-tropical-rhythms`
- `name`: «Тропические ритмы Сейшельских островов»
- `region`: `Сейшелы` (выводится как тег в правом верхнем углу карточки)
- `category`: `expedition` (попадает в карусель «Экспедиционные круизы» на главной)
- `days`: `8`
- `price`: `от €7 025`
- `image`: подходящее изображение островов из существующих ассетов (`islandsImg` — `@/assets/islands.jpg`), чтобы избежать пустой картинки. При желании позже можно заменить на новое фото Сейшел.
- Минимально необходимые поля для совместимости со страницей деталей тура: `subtitle`, `description`, `gallery`, `itinerary` (8 дней), `included`, `notIncluded`, `difficulty`, `groupSize`, `startDates`, `shipName` — заполняются нейтральным экспедиционным контентом по образцу остальных круизов.

### Где появится

- Главная страница → блок «Экспедиционные круизы» (карусель `TourCarousel`).
- Страница `/expedition-cruises` (фильтрует по `category === "expedition"`).
- Страница тура по ссылке `/tour/seychelles-tropical-rhythms`.

### Что НЕ меняется

- Layout и стили карточки `TourCarousel.tsx` не трогаем — тег региона уже выводится из поля `region`.
- Маршрутизация и навигация существующие.
