

## Развёрнутая программа по дням для тура «Большое корейское путешествие и Фестиваль Любви в Намвоне»

Текущий тур `korea-jeju-island` уже содержит правильные название, цены, FAQ и список включений — но программа по дням сейчас в виде кратких резюме. Заменю её на полную развёрнутую версию из вашего текста.

### Что будет сделано

В файле `src/data/tours.ts` обновлю массив `itinerary` тура `korea-jeju-island` (строки 1329–1338).

Каждый день будет содержать:
- **day**: дата (например, `"28 апр."`, `"29 апр."`, `"1 мая"`)
- **title**: название дня (как в блоке 6)
- **description**: полный развёрнутый текст с описанием каждой точки (Мэрия Сеула, Чхонгечхон, Кёнбоккун и т.д.) — все абзацы из присланного текста, объединённые в один развёрнутый параграф через переносы строк, с сохранением структуры.

### Структура 8 дней

1. **28 апр.** — Прибытие в Сеул
2. **29 апр.** — Панорама Сеула: наследие и горизонты (12 точек: Мэрия → Gangnam Style)
3. **30 апр.** — Этнографическая деревня в Йонине + мастер-класс барабанов
4. **1 мая** — Чончжу (6 точек) + Фестиваль Любви в Намвоне
5. **2 мая** — Бамбуковый лес Тамяна, дольмены Хвасун, Наган Ыпсон, сады Сунчхона
6. **3 мая** — Пусан (7 точек: Алмазный мост → пляж Хэундэ)
7. **4 мая** — Кёнчжу (6 точек: Соккурам → пруд Вольчжи)
8. **5 мая** — Отправление

### Что НЕ меняется

- ID, URL, название тура, слоган, цены, даты, FAQ, included/notIncluded, маршрут на карте, изображения
- Только массив `itinerary` обновляется новым подробным контентом
