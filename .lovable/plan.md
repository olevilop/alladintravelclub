

## Исправить кнопку «Главная» в хлебных крошках

### Проблема

Сейчас «Главная» использует `navigate(-1)`, что возвращает на предыдущую страницу в истории браузера, а не на главную. Если пользователь перешёл со страницы категории на тур и нажал «Главная», он вернётся обратно на тур — это неправильно.

### Решение

**Файл: `src/components/Breadcrumbs.tsx`** — заменить логику `handleHomeClick` на простой `navigate("/")`:

```tsx
const handleHomeClick = (e: React.MouseEvent) => {
  e.preventDefault();
  navigate("/");
};
```

Это всегда ведёт на главную страницу. Одна строка изменения.

### Проверено

- «Туры по Японии» в крошках — ведёт на `/japan-tours` — работает корректно
- Полные названия категорий (например, «Туры по Японии» вместо «Япония») — отображаются корректно
