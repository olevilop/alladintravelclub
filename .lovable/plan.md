## Карточка «Технические характеристики» — стиль как в референсе

### Что меняем в `src/pages/cruises/LinerDetailPage.tsx` (правый aside)

1. **Немного шире карточки**
   - Заменить `w-fit max-w-xs ml-auto` на `w-full max-w-sm ml-auto` (≈384px вместо ≈320px), чтобы карточка стала чуть шире, но по-прежнему прижималась к правому краю.
   - Padding оставить `p-5` (или поднять до `p-6` для воздуха внутри).

2. **Заголовок**
   - Оставить `font-serif text-lg`, добавить `uppercase tracking-[0.15em]` — как в референсе («ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ» капсом, разреженный трекинг).

3. **Строки с пунктирной линией-лидером (dot leaders)**
   - Перестроить каждую строку: `<dt>` слева, гибкий пунктирный разделитель по центру, `<dd>` справа.
   - Реализация через flex + псевдо-разделитель:
     ```
     <div class="flex items-baseline gap-2">
       <dt>Длина</dt>
       <span class="flex-1 border-b border-dotted border-foreground/30 translate-y-[-4px]"></span>
       <dd class="font-serif text-primary">170 м</dd>
     </div>
     ```
   - Цифры — `text-primary` (золотой), `font-serif`, размер `text-base` (чуть скромнее текущего `text-lg`, чтобы соответствовать референсу, где цифры и подписи примерно одного размера).
   - Подписи (`dt`) — `text-foreground` обычный sans, `text-sm`.
   - Вертикальные отступы между строками — `space-y-4` (как в референсе, воздушнее текущего `space-y-3`).

4. **Что не меняем**
   - Данные `liner.specs` остаются без изменений — состав строк уже соответствует референсу (Длина, Ширина, Скорость, Пассажиры, Экипаж, Год постройки, Флаг) для лайнеров, где эти поля заполнены. Никаких правок в `src/data/liners.ts`.
   - Sticky-поведение, фон карточки и border сохраняются.
