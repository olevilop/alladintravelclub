## Доработки страницы лайнера (`src/pages/cruises/LinerDetailPage.tsx` + `src/data/liners.ts`)

### 1. Карточка «Технические характеристики» — крупнее и ближе
- Убрать `w-fit` / `max-w-xs` / `ml-auto` — карточка занимает всю ширину правой колонки (`lg:col-span-4`).
- Заголовок чуть крупнее: `text-xl md:text-2xl`, значения `dl` — `text-base`, отступы `space-y-4`, padding `p-7`.
- Минимизировать расстояние до левой колонки: уменьшить gap сетки с `gap-8 lg:gap-12` до `gap-4 lg:gap-6`.

### 2. Галерея — добавить ещё 2 фото
- В `src/data/liners.ts` для всех лайнеров расширить массив `gallery` до **6 элементов** (добавить 2 placeholder-картинки или 2 ассета — для Emerald Kaia и Scenic Eclipse повторно использовать существующие фото судна, для остальных — `placeholder("... 5")`, `placeholder("... 6")`).
- В карусели сохранить 5 карточек в строке (`lg:w-[calc(20%-13px)]`); шестая будет за краем экрана и обеспечит видимую возможность прокрутки + появление правой стрелки.

### 3. Вкладка «Каюты» — расширенное описание (по референсу)
- Расширить тип `LinerCabin` в `src/data/liners.ts`: добавить опциональные `area?: string` (например, `"33 м² (включая веранду 7м²)"`) и `features?: string[]` (маркированный список особенностей).
- Заполнить `area` и `features` для существующих кают (берём содержимое из текущего `description`, дробим на буллеты; где нет данных — оставляем `description`).
- В правой части карточки каюты:
  - Название каюты — `font-serif text-xl uppercase` (как в референсе «ЛЮКС ВЕРАНДА V1»).
  - Под названием — строка `Площадь — {area}` жирным `font-semibold`.
  - Ниже — `<ul>` с маркерами `list-disc list-inside` из `features` (если есть). Если `features` пустой — показываем `description` как сейчас.
- Миниатюра слева остаётся `sm:w-56 aspect-[4/3]`.
