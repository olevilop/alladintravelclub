

## Создать страницу «Спецпредложения»

### Структура страницы `/special-offers`

1. **Hero-баннер** — полноэкранное изображение одного из туров-спецпредложений (случайный выбор), с заголовком «Спецпредложения» и затемнением поверх
2. **Список туров** — все туры из общего массива, отображённые горизонтальными карточками по образцу из скриншота:
   - Слева: фото тура
   - По центру: название (крупное, uppercase) + описание текстом
   - Справа: стоимость (крупная цифра) + длительность (ночей)
3. **Footer** — стандартный

### Файлы

**Создать `src/pages/SpecialOffersPage.tsx`:**
- Импорт всех массивов туров из `@/data/tours`
- Hero с рандомным изображением тура
- Список карточек: каждая карточка — горизонтальный блок (image | text | price), как в референсе
- Каждая карточка кликабельна → `/tour/{id}`
- Navbar + Footer обрамление

**Изменить `src/App.tsx`:**
- Добавить маршрут `/special-offers` → `SpecialOffersPage`

### Дизайн карточки (по референсу)
```text
┌──────────┬────────────────────────────────┬──────────┐
│          │ НАЗВАНИЕ ТУРА (uppercase, bold)│Стоимость │
│  Фото    │                                │  от      │
│  тура    │ Описание тура текстом...       │ 7 242 $  │
│          │                                │Длительн. │
│          │                                │от 13 ноч.│
└──────────┴────────────────────────────────┴──────────┘
```

- На мобильных карточка становится вертикальной (фото сверху, текст, цена внизу)
