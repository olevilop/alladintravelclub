#### 3. Карточки туров (по референсу)
Каждая карточка — горизонтальный блок на светлом фоне:

```text
┌─────────────┬───────────────────────────────────────┬────────────────┐
│             │ НАЗВАНИЕ ТУРА (bold, uppercase, крупн)│ Стоимость от   │
│   Фото      │                                       │   7 242 $      │
│  (фиксир.   │ Описание тура обычным текстом,        │ Длительность   │
│   ширина)   │ без обрезки, полный абзац              │  от 13 ночей   │
│             │                                       │                │
└─────────────┴───────────────────────────────────────┴────────────────┘
```

Ключевые отличия от текущей версии:
- **Убрать** тег региона, ссылку «Подробнее» с стрелкой
- **Название** — крупный жирный uppercase заголовок (не serif italic, а bold)
- **Описание** — обычный текст без `line-clamp`, полный абзац
- **Цена** — «Стоимость от» мелким текстом сверху, крупная цифра цены, затем «Длительность» и «от {days} ночей»
- **Без разделительной линии** между секциями внутри карточки
- **Без hover-эффектов** на изображении
- Фон карточки — белый/светлый, без бордера с hover
