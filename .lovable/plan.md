## Исправление хлебных крошек на страницах круизов

### Проблема
На семи страницах раздела «Круизы» breadcrumbLabel не содержит слова «Круизы по», а только название региона. Это не соответствует единому формату (уже применённому на страницах Африки, Антарктиды и Арктики).

### Изменения

Обновить `breadcrumbLabel` в следующих файлах:

1. `src/pages/cruises/OceaniaCruisesPage.tsx`
   - С `Австралия и Океания` на `Круизы по Австралии и Океании`

2. `src/pages/cruises/MiddleEastCruisesPage.tsx`
   - С `Ближний Восток` на `Круизы по Ближнему Востоку`

3. `src/pages/cruises/NorthAmericaCruisesPage.tsx`
   - С `Северная Америка` на `Круизы по Северной Америке`

4. `src/pages/cruises/SouthAmericaCruisesPage.tsx`
   - С `Южная Америка` на `Круизы по Южной Америке`

5. `src/pages/cruises/RussiaCruisesPage.tsx`
   - С `Россия` на `Круизы по России`

6. `src/pages/cruises/AsiaCruisesPage.tsx`
   - С `Азия` на `Круизы по Азии`

7. `src/pages/cruises/EuropeCruisesPage.tsx`
   - С `Европа` на `Круизы по Европе`

### Проверка
После изменений все страницы раздела «Круизы» будут использовать единый формат хлебных крошек: «Главная → Круизы по <региону>».
