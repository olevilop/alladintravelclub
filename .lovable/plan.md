Уменьшить размеры всех элементов карточки:

1. **Изображение** (строка 49): `md:w-[300px] md:min-h-[220px]` → `md:w-[220px] md:min-h-[160px]`
2. **Текстовый блок** (строка 59): паддинг `p-6 md:p-8` → `p-4 md:p-5`
3. **Заголовок** (строка 60): `text-xl md:text-2xl` → `text-base md:text-lg`
4. **Описание** (строка 63): `mt-3` → `mt-2`, обрезать текст до 2 строк через `line-clamp-2`
5. **Блок информации** (строка 69): паддинг `p-6 md:p-8` → `p-4 md:p-5`, ширина `md:w-[240px]` → `md:w-[200px]`, gap `space-y-3` → `space-y-2`

7. **Отступы между карточками** (строка 43): `space-y-6` → `space-y-4`
