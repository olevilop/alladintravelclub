

## Исправить маппинг хлебных крошек для круизов

### Проблема

В `regionToBreadcrumb` есть несоответствия с реальными данными туров:

1. В данных туров регион — `"Антарктида"`, а в маппинге — `"Антарктика"` → крошка не найдётся
2. Регион `"Африка"` (тур «Сафари в Серенгети») — нет маппинга
3. Классические круизы (tours.slice(4)) имеют регионы `"Арктика"`, `"Острова"`, `"Азия"`, `"Южная Америка"` — для них нет маппинга на «Классические круизы»

### Текущая разбивка туров

```text
Экспедиционные (slice 0-3):
  "Арктика"      → Экспедиционные круизы ✓
  "Антарктида"   → ??? (маппинг на "Антарктика") ✗
  "Антарктида"   → ??? ✗
  "Африка"       → ??? ✗

Классические (slice 4+):
  "Арктика"      → Экспедиционные круизы (неправильно!) ✗
  "Острова"      → ??? ✗
  "Азия"         → ??? ✗
  "Южная Америка"→ ??? ✗
```

### Проблема с текущим подходом

Маппинг `region → breadcrumb` не подходит, потому что один и тот же регион («Арктика») может относиться и к экспедиционным, и к классическим круизам. Нужен другой механизм.

### Решение

Добавить в тип `Tour` необязательное поле `category` и использовать его для крошек с приоритетом над `region`.

**Файл: `src/data/tours.ts`**

1. Добавить `category?: string` в интерфейс `Tour`
2. Проставить `category: "expedition"` для туров 0-3 и `category: "classic"` для туров 4-7
3. Добавить маппинг `categoryToBreadcrumb`:
   ```ts
   export const categoryToBreadcrumb: Record<string, { label: string; path: string }> = {
     "expedition": { label: "Экспедиционные круизы", path: "/expedition-cruises" },
     "classic": { label: "Классические круизы", path: "/classic-cruises" },
   };
   ```
4. Исправить `"Антарктика"` → `"Антарктида"` в `regionToBreadcrumb` (на случай использования в другом месте)

**Файл: `src/pages/TourDetail.tsx`**

Изменить логику крошек — сначала проверять `category`, потом `region`:
```tsx
const crumb = tour.category
  ? categoryToBreadcrumb[tour.category]
  : regionToBreadcrumb[tour.region];

<Breadcrumbs items={[
  { label: crumb?.label || tour.region, href: crumb?.path || "/" },
  { label: tour.name }
]} />
```

### Результат

- Тур из экспедиционных круизов → `Главная > Экспедиционные круизы > Название`
- Тур из классических круизов → `Главная > Классические круизы > Название`
- Туры по странам (Япония, Китай и т.д.) — без изменений
