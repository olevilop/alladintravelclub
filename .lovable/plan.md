# Гранд Тур по Китаю — новый тур в разделе «Туры по Китаю»

## 1. Данные тура (`src/data/tours.ts`)

Добавить новый объект в массив `chinaTours`:

- `id: "china-grand-tour-2026"`
- `name: "Гранд Тур по Китаю"`
- `region: "Китай"` → автоматически даст бейдж «КИТАЙ» в правом верхнем углу TourCard (карусель уже применяет `uppercase`).
- `category: "Групповой тур"` (НЕ `expedition`/`classic` → в сайдбаре будет иконка «Экскурсионный тур», нет иконки корабля).
- `days: 11`, `groupSize: "от 2 до 9 человек"`.
- `price: "от 12 166 ¥"` (нижняя цена 6–9 чел / TWIN).
- `subtitle: "От Запретного города до огней Шанхая — все жемчужины Китая за 11 дней"`.
- `image` / `gallery`: 5 заглушек `https://placehold.co/1600x900?text=...` (Beijing, Xian, Luoyang, Suzhou, Shanghai).
- `description`: текст из ТЗ (3 абзаца через `\n`).
- `itinerary`: 11 дней по тексту ТЗ (питание включено в `description` каждого дня).
- `included` / `notIncluded`: списки из ТЗ. В `included` добавить отдельной строкой пометку про отели как `extras` или последним пунктом «⚠️ Отели не фиксированы…» — вынесу в `extras`.
- `extras`: блок «Доплаты и опции» — текстом с маркерами:
  - Купе вместо плацкарта Пекин–Сиань: +170 ¥/чел
  - Высокоскоростной поезд (включая 1 доп. ночь): TWIN +850 ¥, SGL +1100 ¥, EXB +850 ¥, без места +678 ¥
  - Шанхайский Диснейленд (день 10): ~700 ¥/чел (цена уточняется)
  - `!!!⚠️ Отели не фиксированы — возможна замена на аналогичный вариант по предпочтениям.`
- `startDates: ["По запросу — 2026"]` (в ТЗ нет конкретных дат → плейсхолдер для селектора даты).
- Без `badge`, без `shipName` → не попадёт в SpecialOffers визуально как спец, но всё равно входит в общий пул. ТЗ требует «не должен попадать в Спецпредложения» → см. п.4.

### Новое поле модели `Tour` (`src/data/tours.ts`)

Расширить `interface Tour` полем:
```ts
groupPricing?: {
  groups: { label: string; rows: { label: string; price: string }[] }[];
  defaultGroup?: string;
};
```

Заполнить 4 группами (2, 3, 4–5 (по умолчанию), 6–9 чел) × 4 строки (TWIN / SGL / EXB / Без места). Прочерки для 2-чел — строка `price: "—"` отрисовывается серым.
