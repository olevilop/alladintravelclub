

## Замена тура «Дворцы и храмы Сеула» на «9 дней по Корее и фестиваль масок в Андоне»

Полная замена содержимого тура `korea-seoul-palaces` новыми данными и добавление поддержки кастомных FAQ для отдельных туров.

### Что будет сделано

**1. Генерация 5 новых изображений через AI**

Сюжеты:
1. Фестиваль масок в Андоне (танцоры в масках)
2. Дворец Кёнбоккун в Сеуле
3. Деревня ханок в Чончжу (черепичные крыши)
4. Буддийский храм Пульгукса / грот Соккурам в Кёнчжу
5. Пусан — деревня Камчхон или вид на море

Файлы: `src/assets/korea-andong-1.jpg` ... `korea-andong-5.jpg`

**2. Расширение интерфейса Tour (`src/data/tours.ts`)**

Добавить опциональное поле:
```ts
faq?: { q: string; a: string }[];
```

**3. Замена данных тура `korea-seoul-palaces` (`src/data/tours.ts`)**

- `id`: `korea-seoul-palaces` (без изменений — сохраняет URL)
- `name`: «9 дней по Корее и фестиваль масок в Андоне»
- `subtitle`: «Познакомьтесь с Кореей через её живые традиции...»
- `price`: «от $1 549»
- `days`: 9
- `region`: «Южная Корея»
- `startDates`: [«18.09 — 26.09.2026»]
- 9-дневный маршрут (дни с конкретными датами — 18–26 сент.)
- `included` и `notIncluded` по предоставленным спискам
- `gallery`: 5 новых изображений
- `excursionPricing`: 3 экскурсии (Вечерний Токио → Вечерний Сеул нет, это именно «Вечерний Токио», «Традиции Токио», «Нара и Осака» — пользователь указал эти названия, оставляю как есть)
- `faq`: 9 кастомных вопросов-ответов из блока 10

**4. Обновление маршрута на карте (`src/data/tourRoutes.ts`)**

Заменить точки `korea-seoul-palaces`:
Сеул → Йонин → Сувон → Чончжу → Хвасун → Сунчхон → Пусан → Кёнчжу → Андон → Сеул (10 точек)

**5. Обновление FAQSection (`src/components/FAQSection.tsx`)**

- Добавить пропс `customFaq?: { q: string; a: string }[]`
- Если передан — использовать вместо стандартных вопросов

**6. Обновление TourDetail (`src/pages/TourDetail.tsx`)**

- Передать `tour.faq` в `<FAQSection>`:
```tsx
<FAQSection isCruise={isCruise} customFaq={tour.faq} />
```

### Технические детали

- ID тура не меняется → URL `/tour/korea-seoul-palaces` сохраняется
- Импорты новых ассетов добавляются в начало `tours.ts`
- Дни маршрута используют строковый формат с датами (как `"18 сент."`)
- Роутинг и навигация не требуют изменений
