## Что я нашёл

Страница `src/pages/cruises/RussiaCruisesPage.tsx` сейчас рендерит `russiaTours` целиком:

```tsx
tours={russiaTours}
title={<>Круизы по <span className="italic">России</span></>}
```

Но `russiaTours` (`src/data/tours.ts`, строки 2805–…) содержит **наземные туры**, а не круизы:
- `russia-baikal` — Байкал
- `russia-kamchatka` — Камчатка
- `russia-altai` — Алтай
- `russia-spb-white-nights` — Петербург
- `russia-golden-ring` — Золотое кольцо

Ни у одного из них нет признака круиза (категории `expedition`/`classic` или слова «круиз» в названии). При этом другие круизные страницы (`OceaniaCruisesPage`, `MiddleEastCruisesPage`, `AfricaCruisesPage`, …) фильтруют массив `tours` по `regionToContinent[t.region] === "<континент>"`, то есть берут именно круизы из `tours`.

В массиве `tours` сейчас **нет ни одного круиза с регионом «Россия»** — поэтому правильно отфильтрованная страница окажется пустой.

Дополнительно нарушает логику запись `"Россия": "Азия"` в `regionToContinent` — это означает, что любой круиз с регионом «Россия» попадёт на страницу «Круизы по Азии», а не «Круизы по России».

## Варианты исправления

Нужно решение по содержимому страницы. Предлагаю обсудить варианты:

1. **Вариант A — Очистить и подготовить под будущие круизы.** Сделать страницу пустой по аналогии с новой «Европой»: фильтровать `tours` по региону «Россия» (и по желанию убрать запись `"Россия": "Азия"` из `regionToContinent`, чтобы будущие русские круизы не уезжали в «Азию»). Сейчас страница будет пустой — нужны заглушка/CTA.

2. **Вариант B — Оставить наземные туры, но переименовать страницу.** Например «Туры по России» вместо «Круизы по России», т.к. контент по факту наземный. Меню «Круизы → Россия» тогда нужно убрать или перенести в раздел «Туры».

3. **Вариант C — Добавить реальные речные/морские круизы по России в данные** (Волга, Енисей, Камчатка-морской и т.п.), отфильтровать `tours` по региону «Россия» и показать только их. Наземные `russiaTours` останутся для `/russia-tours`.

## Что я рекомендую

Вариант C даёт логически чистую страницу «Круизы по России», но требует данных по реальным круизам. Если данных пока нет — временно вариант A с заглушкой «Скоро» и обязательно правкой `regionToContinent` (`"Россия": "Россия"`, либо отдельный континент), чтобы Россия не считалась Азией.

Дальше — нужен ваш выбор: A, B или C, и для C — список круизов, которые добавить.
