Создаётся по образцу `seychelles-tropical-rhythms` / `china-yangtze-cruise-2026`. Использует существующие компоненты — никаких новых блоков не требуется (`TourHero`, `TourItinerary`, `TourPricing` с `cabinPricing`, `TourIncluded`, `TourTerms`, ship-блок через `shipName`/`shipImage`/`extras`, `TourManager`, `TourBookingForm`, `Breadcrumbs` уже работают).

- `region: "Камбоджа"` (для бейджа страны в правом верхнем углу карточки; полный заголовок «Вьетнам — Камбоджа» — в `subtitle`)

## Что произойдёт автоматически

- Страница `/tour/vietnam-cambodia-mekong-cruise` через динамический роут в `App.tsx` (правится не нужно).
- Карточка появится в `/expedition-cruises` (фильтр `category === "expedition"`).
- Тур войдёт в карусель «Спецпредложения» на главной (берёт случайные 8 из всех массивов).
- Бейдж «🇷🇺 РУССКАЯ ГРУППА» отрисуется на `TourCard` и в `TourInfo` сайдбаре (логика уже есть для других русских групп).
- `TourBookingForm` покажет селектор «Период заезда» с двумя вариантами (логика уже работает с массивом `startDates`).
