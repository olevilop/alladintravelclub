

## Добавить тип круиза и материк в блок краткой информации

**Что делаем:** В сайдбаре на странице деталей тура (блок «Краткая информация», строки 193–217 в `TourDetail.tsx`) для экспедиционных круизов добавляем две строки:
- «Экспедиционный круиз» — тип тура
- Название материка (например, «Антарктида») — уже есть как `tour.region`, но нужно добавить отдельной строкой с иконкой Globe/Compass если region отличается от текущего отображения

**Файл: `src/pages/TourDetail.tsx`**

1. Импортировать иконку `Compass` из lucide-react
2. После заголовка карточки (строка 174, `tour.name`) и перед блоком дат добавить условный блок для экспедиционных круизов:

```tsx
{tour.category === "expedition" && (
  <div className="flex items-center gap-3 text-sm text-foreground/80">
    <Compass className="w-4 h-4 text-primary shrink-0" />
    <span>Экспедиционный круиз · {tour.region}</span>
  </div>
)}
```

Это добавит строку «Экспедиционный круиз · Антарктида» (или «· Арктика», «· Африка») для всех туров с `category: "expedition"`. Никаких изменений в данных не требуется — `region` уже содержит название материка/региона.
