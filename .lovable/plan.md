# Страница «Круизы по Антарктиде»

## Что сделать

Наполнить уже существующую страницу `/cruises/antarctica` (сейчас пустая заглушка) реальным контентом — по дизайну и структуре идентично странице «Экспедиционные круизы». На страницу должны попадать ВСЕ туры (и из категории `expedition`, и из категории `classic`), у которых в данных тура указан регион `Антарктида`.

Переходы в шапке (Круизы → Антарктида) и в подвале (Круизы → Антарктида) уже ведут на `/cruises/antarctica` — отдельно их править не нужно, страница автоматически заработает.

## Изменения

### 1. `src/pages/cruises/AntarcticaCruisesPage.tsx`
Заменить заглушку с `tours={[]}` на реальную страницу:
- Импортировать `tours` из `@/data/tours`.
- Отфильтровать: `tours.filter(t => t.region === "Антарктида")` — это даст и экспедиционные, и классические круизы по Антарктиде.
- Передать в `CategoryToursPage`:
  - `title`: «Круизы по **Антарктиде**» (вторая часть — italic, как на странице экспедиционных).
  - `subtitle`: «К ледяному континенту».
  - `breadcrumbLabel`: «Антарктида».
  - `breadcrumbParent`: `{ label: "Круизы", href: "/expedition-cruises" }` (см. п.3).
  - `hideSpecialOfferTag`: чтобы карточки не показывали тег спецпредложения (как на странице «Экспедиционные круизы»).
  - `category`: не передавать (на странице будут смешанные категории; блок «Похожие туры» не должен ограничиваться одной категорией).

### 2. `src/components/Breadcrumbs.tsx`
Уже умеет рендерить любой массив `items` с опциональным `href`, ссылка «Главная» уже кликабельна. Доп. правок не требуется.

### 3. `src/pages/CategoryToursPage.tsx`
Добавить опциональный проп `breadcrumbParent?: { label: string; href: string }`. Если передан — вставлять его в массив крошек перед текущим элементом, чтобы получилось:

```text
Главная › Круизы › Антарктида
```

Где «Главная» и «Круизы» кликабельные, «Антарктида» — текущая страница (жирная, без ссылки). На остальных страницах, где `breadcrumbParent` не передан, поведение не меняется.

### 4. Навигация в шапке/подвале
Уже ведёт на `/cruises/antarctica` — менять не нужно.

## Что НЕ меняется
- Файлы данных туров (`src/data/tours.ts`).
- Карточка тура и её разметка.
- Остальные страницы категорий и круизов.
- Маршрутизация в `App.tsx` (маршрут уже есть).
