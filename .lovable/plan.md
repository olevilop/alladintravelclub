

## Нарисовать маршрут линией на карте в блоке «Карта маршрута»

**Задача:** Заменить пустой iframe OpenStreetMap на интерактивную карту с нарисованным маршрутом (линия между точками + маркеры) прямо в компоненте `RouteMap`.

**Подход:** Вместо iframe использовать SVG-оверлей поверх статических тайлов OpenStreetMap. Точки маршрута проецируются из lat/lng в пиксельные координаты по проекции Меркатора, затем рисуется polyline (линия маршрута) и круглые маркеры с номерами.

### Что увидит пользователь

- Карта с тайлами OpenStreetMap (без iframe, через `<img>` тайлов)
- Линия маршрута (золотая/primary), соединяющая все точки по порядку
- Пронумерованные маркеры на каждой точке
- Список точек под картой (как сейчас)

### Техническая реализация

**Файл: `src/components/RouteMap.tsx`** — полная переработка:

1. Рассчитать bbox маршрута (уже есть) и определить zoom-уровень + центр для тайлов
2. Загрузить сетку тайлов OSM через `<img>` теги в CSS grid
3. Наложить SVG поверх карты с:
   - `<polyline>` — линия маршрута через все точки
   - `<circle>` + `<text>` — маркеры с номерами на каждой точке
4. Функции `latLngToPixel()` для проекции Меркатора в пиксельные координаты тайловой сетки

Компонент останется полностью клиентским, без внешних библиотек. Используются только стандартные OSM тайлы (`tile.openstreetmap.org`) + SVG.

Один файл, одна переработка.
