

## Убрать дедупликацию маршрута в сайдбаре TourDetail

**Проблема:** В сайдбаре карточки тура (строка с иконкой Route) маршрут отображается как «Буэнос-Айрес → Ушуайя → Пролив Дрейка → Антарктида → Ушуайя» — пропущен второй «Пролив Дрейка». Это из-за дедупликации в `TourDetail.tsx`, строка 233.

**Решение:** Убрать фильтр дедупликации и выводить все точки маршрута по порядку.

### Техническая деталь

**Файл: `src/pages/TourDetail.tsx`**, строка 233 — заменить:

**Было:**
```ts
{routePoints.map(p => p.label).filter((v, i, a) => a.indexOf(v) === i || i === a.length - 1).join(" → ")}
```

**Станет:**
```ts
{routePoints.map(p => p.label).join(" → ")}
```

Одна правка, один файл.
