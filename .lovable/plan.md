## План: Страница "Наша команда"

### Цель
Создать новую страницу с информацией о команде, привязать её к слову "Контакты" в шапке и к слову "Наша команда" в подвале.

### Шаги

#### 1. Создание страницы команды
- **Файл:** `src/pages/TeamPage.tsx`
- **Контент:** 4 карточки менеджеров (Виктория, Мария, Елена, Юля) с данными, предоставленными пользователем. Каждая карточка включает: фото, имя, роль, описание, девиз, контакты (телефон, email, WhatsApp, Telegram).
- **Дизайн:** В стиле проекта — светлый фон, золотые акценты (`text-gold-gradient`), serif-шрифты для заголовков, sans-serif для текста. Структура страницы: Navbar → Breadcrumbs → Hero-заголовок → Сетка карточек → Footer. Адаптивная сетка 1–2 колонки.
- **Исправление данных:** Исправить отсутствующие закрывающие кавычки у Юли в `role` и `telegram`.

#### 2. Роутинг
- **Файл:** `src/App.tsx`
- Добавить `import TeamPage from "./pages/TeamPage.tsx";` и маршрут `<Route path="/team" element={<TeamPage />} />`.

#### 3. Шапка — Navbar
- **Файл:** `src/components/Navbar.tsx`
- В массиве `navLinks` заменить `href: "#contact"` на `href: "/team"` для пункта "Контакты".
- Функция `scrollTo` уже обрабатывает не-якорные ссылки (через `navigate`), поэтому изменение href будет работать.

#### 4. Подвал — Footer
- **Файл:** `src/components/Footer.tsx`
- В массиве `footerLinks`, в блоке "Компания", заменить статичный текст "Наша команда" на кликабельную ссылку `<Link to="/team">` (аналогично тому, как сделано для "О нас", "Политика конфиденциальности" и т.д.).

### Технические детали
- Используем существующие компоненты: `Navbar`, `Footer`, `Breadcrumbs`.
- Иконки контактов: `Phone`, `Mail`, `MessageCircle` из `lucide-react` + SVG для Telegram.
- Адаптив: `grid-cols-1 md:grid-cols-2` для карточек.
